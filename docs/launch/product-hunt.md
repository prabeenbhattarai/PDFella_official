## Maker's first comment
> Hi Product Hunt! 👋
>
> I built PDFella because every "free" PDF editor I tried did the same thing: when you want to fix a typo, it puts a white box over the old text and a new text box on top, in a font that doesn't match. It looks patched.
>
> PDFella edits the text that's actually in the PDF. Double-click a line, change it, and it reuses the PDF's own font where possible (or a metric-identical match like Carlito for Calibri), so the result looks like it was never edited.
>
> A few other things I cared about:
> • No account, no watermark, no daily limits on the core tools
> • Editing, signing, redaction, merge and compress run in your browser, so your files never leave your device
> • Redaction really removes the content from the file, not just hides it
>
> It's early, and I'd love your feedback: what PDF task do you still dread? I'll be here all day answering questions.
